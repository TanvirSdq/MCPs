# MCPs

Model Context Protocol (MCP) experimentation and prototyping.

## Overview

A repository for experimenting with Model Context Protocol (MCP) implementations, custom tool servers, and agent integrations.

## Features

- Custom MCP server prototypes and experiments
- Tool and resource integrations
- Local environment testing and configuration

## Tech Stack

- Python
- Model Context Protocol (MCP)

## Getting Started

### Clone Repository

```bash
git clone https://github.com/TanvirSdq/MCPs.git
cd MCPs
```

### Environment Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
```
